# CodeAlpha Task 2

## Project Title
Registration and Login System (C++)

## Description
This project is developed in C++ as part of the CodeAlpha internship. It implements a simple Registration and Login System using Object-Oriented Programming concepts. Users can register with a username and password and log in using their credentials.

## Features
- User Registration
- User Login
- Password Validation
- File Handling
- Object-Oriented Programming (OOP)

## Technologies Used
- C++
- Visual Studio Code
- Git & GitHub
